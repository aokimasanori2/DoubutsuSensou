# どうぶつ戦争 — 参照したルール

出典: https://chatgpt.com/share/6ac27b91-c3ac-83ee-be18-0c948d50e10f
2026-10-05に共有会話の該当メッセージと盤面画像を確認。
会話は画面位置に応じて本文を省略するため、各メッセージへ移動して読む必要がある。

## 0.2.0で実装した範囲

- 1台のAndroidで2人が交互に操作する。
- 1人10個: ライオン・トラ・チーター・きつね・うさぎ・とり各1、もぐら・おとしあな各2。
- 盤面は横6列。最終の赤屋根・青屋根の画像から、上の草4行・川1行・下の土4行と読み取った。
- 橋は川の2列目と5列目（0始まりでは1,4）。橋の出口はその上下のマス。
- 最奥行の3,4列目を結合して1つの家とする。家の容量は1駒。草側は赤屋根、土側は青屋根。
- 自分の陣地のどこにでも初期配置可能。橋と川は初期配置場所に含まない。
- おとしあなは橋の出口に置けない。家には置ける。
- とりは家に入れないため、初期配置でも家に置けない。
- 駒をタップ → マスをタップ。確定前は並べ替え自由。全10個の配置後に確定。
- 草の配置 → 土に渡す秘密画面 → 土の配置 → 両者準備完了。
- 相手の駒は「？」で、正体を示す名前や画像をUI・読み上げに出さない。

## 次の実装で用いる確定事項

- 通常の動物は上下左右に1マス。味方を飛び越えず、川に入らず橋を使う。
- チーターは直線移動。味方・川で進路が遮られる。敵に接触すると戦闘。
- とりは一方向に何マスでも飛べて、味方・敵・川を飛び越せる。家には入れない。
- おとしあなは動かせない。
- 強さの基本順はライオン > トラ > チーター > きつね > うさぎ > もぐら。
- 例外: うさぎはライオンに勝つ。とりはきつね・うさぎ・もぐらに勝つ。
- 同種同士は相打ちで両方消える。
- とり・もぐらはおとしあなに勝つ。それ以外の動物が落ちると動物とおとしあなの両方が消える。
- 家は中央2列のどちらからでも入れる。とり以外がおうちに帰る、または相手の動かせる駒がなくなると勝利。
- 戦闘中・戦闘後も相手の正体や理由は表示せず、盤面の結果だけを表示する。
- 1手ごとの交互制。端末を渡す秘密画面を挟み、次の人が「じゅんびOK！」を押す。

この版は配置までを実装し、移動や戦闘の処理はまだ持たない。
